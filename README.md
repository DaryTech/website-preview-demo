# website-preview-demo

The sample website from the Dary Technologies lesson **GitHub to Vercel: put your website online and share one link with a client**.

It is one plain HTML file with sample content: no build step, forms, database, analytics or outside files. Search engines are asked not to index it.

## Publish it yourself on Vercel

1. Fork or copy this repository to your own GitHub account.
2. In Vercel, choose **Add New**, then **Project**, and connect GitHub if asked.
3. Find the repository and choose **Import**.
4. Keep the root directory as is, choose the **Other** framework preset, and leave the build command empty.
5. Choose **Deploy**. When the status shows Ready, open the link and share it.

## Run it locally

Run `python3 -m http.server 8766` in this folder and open `http://localhost:8766`.
